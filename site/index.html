The problem

Dashboard apps live exactly where you can't see them.

When you're rendering, gaming, or SSH'd into a headless box, the monitor on screen is the last thing you can look at. resmon24 moves the numbers onto dedicated hardware.

01 / Screen

Screen real estate

Overlay widgets compete with your work. A 0.96" OLED on the desk competes with nothing.

02 / Fullscreen

Full-screen & headless

Fullscreen workloads hide every widget. Headless machines have no widgets at all. The display still works.

03 / Always-on

Glanceability

One look tells you CPU, memory, GPU and thermals — and flips to a clock when the desktop is idle.

How it works

Three moving parts. One wire contract.

The desktop samples hardware, the firmware renders it, and a schema-first protocol keeps both sides in lockstep.

Step 01

Desktop samples

Electrobun + Bun reads CPU / RAM / GPU / temperature and pushes samples over a local WebSocket once per second.

Step 02

Device connects

mDNS finds the desktop automatically. First boot opens a captive portal for WiFi SSID, password, and timezone.

Step 03

OLED renders

The resource view shows while a session is live — and switches to clock + date within a second when it isn't.

Features

Built to be boring in the best way.

No accounts, no telemetry, no dashboards in a browser tab. Just a LAN, a tiny screen, and a protocol that can't drift.

F-01 Schema-first protocol JSON Schema is the single source of truth. TypeScript and C++ types are generated — desktop and firmware can never disagree.
F-02 Captive-portal onboarding Join the device's AP, enter SSID / password / timezone. Reconfigure without ever reflashing firmware.
F-03 Adaptive display CLOCK ⇄ RESOURCE switches within 1 s of session changes. A dead panel is a wasted panel.
F-04 Featherweight footprint Targets < 2% CPU and < 150 MB RSS while streaming. p95 metric freshness ≤ 2 s at a 1 s push interval.
F-05 mDNS discovery The device finds the desktop on its own. No IPs, no ports, no setup screens to poke through.
F-06 Fully local Nothing leaves your LAN. The only outbound traffic is NTP — for the clock face.

Quick start

From clone to first metric.

Prerequisites: Bun ≥ 1.1, PlatformIO, an ESP8266 board (e.g. Wemos D1 mini) and an SSD1306 128×64 I2C OLED.

Terminal
# Desktop — metric collector + WebSocket server
cd apps/desktop && bun install
bun run dev

# Firmware — flash the device
cd apps/firmware && pio pkg install
pio run --target upload
pio device monitor      # serial console @ 115200

# First boot opens a captive portal:
#   join AP -> enter SSID / password / timezone -> done

# Package a Linux build (.AppImage / .deb)
cd apps/desktop && bun run package:linux
